# BlueLingo Translation Workspace

Microsoft Translator V2 Connector を利用した Power Apps Code Apps のサンプルアプリです。

GitHub Codespaces と Power Apps Code Apps を利用し、React + TypeScript で多言語翻訳アプリを構築しています。

## 概要

BlueLingo Translation Workspace は、Microsoft Translator V2 コネクターを利用した翻訳アプリです。

Power Apps Code Apps が生成する型付き TypeScript サービスを利用して、React アプリから Power Platform コネクターを呼び出しています。

### 主な機能

- 言語自動検出
- 多言語翻訳
- 対応言語一覧取得
- 翻訳元／翻訳先切り替え
- 翻訳結果コピー
- レスポンシブ対応
- Fluent UI アイコン利用
- Power Apps Code Apps 対応
